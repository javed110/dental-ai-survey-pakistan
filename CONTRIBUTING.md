# Contributing

Keep participant-level files, fitted model objects and private correspondence out of this public repository. Review docs/METHODS.md and docs/DATA_STATUS.md before proposing methodological changes. Preserve the cross-sectional and measurement limits, reference results and explicit data-access status. Run `python tests/check_public_release.py` before a release. CI checks committed aggregates and parses the R code; full analyses require the approved local data package and are not executed in public CI.
